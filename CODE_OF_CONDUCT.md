# Code of Conduct

We want Flying Money to be a welcoming project for everyone, whatever their background, identity or level of
experience.

**Expected:** be kind and patient, assume good intent, give and take constructive feedback gracefully, and focus on
what is best for the people who use the project.

**Not acceptable:** harassment, insults or personal attacks; discriminatory or sexualised language or imagery; publishing
someone's private information; and any conduct that would reasonably be considered inappropriate in a professional
setting.

**Scope:** this applies in all project spaces (issues, pull requests, discussions) and when representing the project
elsewhere.

**Enforcement:** report problems privately to the maintainers by opening a GitHub security advisory on this repository
(it is private) or, if that isn't available, an issue titled "Conduct contact request" without details. Maintainers
will review every report, keep it confidential, and may warn, temporarily ban or permanently ban anyone who breaks
these rules.

This code is adapted from the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/),
version 2.1.
